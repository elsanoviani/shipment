# Shipment API

REST API untuk Shipment Auth menggunakan Go.

## Fitur
- Register
- Login
- Get user Profile
- Update user Profile

## Instalasi
1. Clone repository:
```bash
git clone https://github.com/elsanoviani/shipment.git
cd shipment
```
2. Clone repository:
```bash
go mod tidy
```

3. Jalankan server:
```bash
go run main.go
```
